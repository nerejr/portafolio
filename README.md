# Portafolio de Nereyda Jiménez

Portafolio docente de artes de Nereyda Jiménez Rodríguez. Presenta su experiencia en educación artística, mediación cultural y producción de materiales educativos.

## Contenido

- Perfil y experiencia docente
- Habilidades y técnicas artísticas
- Muestras educativas en video
- Información de contacto

## Uso local

```bash
python3 -m http.server 8000
```

Después, abre `http://localhost:8000` en tu navegador.

## Tecnologías

HTML, CSS y JavaScript, sin proceso de compilación.
